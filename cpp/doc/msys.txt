윈도우용 라이브러리 관리 

pacman.exe 이용 기본적인 외부라이브러리는 이걸 이용해서 받도록 하자.

.\pacman.exe -Ss <원하는 패키지명칭> 
검색해서 나오면 ucrt (유니버살 c 런타임) 어쩌고 저쩌고 포함된 놈으로 설치 

.\pacman.exe -S <패키지명> 설치 .. msys 접속해서 하면 오류 안나는데 윈도우에서 직접 실행하면 일부 스크립트 오류남 왠만하면 msys에서 실행하라 
                          크게 문제 되는 케이스가 있을수 있음 

.\pacman.exe -Qs <패키지명> 설치된거 출력 

# 원격 저장소에서 라이브러리 검색 (예: mariadb)
pacman -Ss mariadb

# 내 컴퓨터에 이미 설치된 라이브러리 목록에서 검색
pacman -Qs mariadb

# 설치된 특정 패키지의 상세 정보 확인
pacman -Qi 패키지명

# 404 에러 방지용 서버 주소록 최신화 (필수)
pacman -Sy

# UCRT64용 마리아디비 라이브러리 정석 설치
pacman -S mingw-w64-ucrt-x86_64-libmariadbclient

# 컴파일러 및 설치된 모든 라이브러리 일괄 최신화
pacman -Syu

# 지정한 딱 1개의 패키지만 삭제
pacman -R 패키지명

# 패키지와 함께 깔려왔던 의존성 찌꺼기까지 묶어서 삭제 (추천)
pacman -Rs 패키지명

# 다른 프로그램이 안 쓰는 고립된 파일까지 추적하여 전면 삭제
pacman -Rsu 패키지명

# 다운로드 임시 캐시 파일 전면 삭제 (디스크 용량 확보)
pacman -Scc

# 내 컴퓨터에 남은 불필요한 고립 찌꺼기(Orphan) 목록 조회
pacman -Qdtq

# [일반 CMD/Bash용] 고립된 찌꺼기 라이브러리 일괄 자동 청소
pacman -Rsu $(pacman -Qdtq)

# [윈도우 파워쉘용] 고립된 찌꺼기 라이브러리 일괄 자동 청소
.\pacman.exe -Rsu $(.\pacman.exe -Qdtq)
