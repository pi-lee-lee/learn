아름다운 수프 문서¶
HTML 및 XML 파일에서 데이터를 가져오기 위한 아름다운 Soupis aPython 라이브러리입니다. 이는 여러분이 선호하는 파서와 함께 작동하여 구문 분석 트리를 탐색, 검색 및 수정하는 관용적인 방법을 제공합니다. 이는 일반적으로 프로그래머의 작업 시간 또는 며칠을 절약해 줍니다.
이 지침은 뷰티플수프 4의 모든 주요 기능을 예시와 함께 설명합니다. 라이브러리가 무엇인지, 어떻게 작동하는지, 어떻게 사용하는지, 원하는 대로 작동하게 만드는 방법, 기대에 어긋날 경우 어떻게 해야 하는지 보여드리겠습니다.
이 문서는 뷰티플수프 버전 4.15.0을 다룬다. 이 문서의 예제는 Python 3.8용으로 작성되었습니다.
BeautifulSoup 3에 대한 문서를 찾고 있을 수도 있습니다. 그렇다면 BeautifulSoup 3은 더 이상 개발되지 않으며 이에 대한 모든 지원이 2020년 12월 31일에 중단되었음을 알아야 합니다. BeautifulSoup 3과 Beautiful Soup 4의 차이점에 대해 알고 싶다면 BS4로 코드 포팅을 참조하세요.
이 문서는 Beautiful Soup 사용자에 의해 다른 언어로 번역되었습니다:
  도움 받기¶
  Beautiful Soup에 대해 질문이 있거나 문제가 발생하면 토론 그룹에 메일을 보내세요. 문제가 HTML 문서 구문 분석과 관련된 경우 해당 문서에 대해 Diagnostic() 함수가 말하는 내용을 언급해야 합니다.
  이 문서의 오류를 보고할 때 어떤 번역을 읽고 있는지 언급해 주세요.
    API 문서¶
    이 문서는 사용 설명서처럼 작성되었지만 BeautifulSoup 소스 코드에서 생성된 전통적인 API 문서도 읽을 수 있습니다. 뷰티플수프의 내부나 이 문서에서 다루지 않은 기능에 대한 자세한 내용을 알고 싶다면 API 문서를 시도해 보세요.
